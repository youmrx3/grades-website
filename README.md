# Portail des notes

Page statique pour afficher les notes des étudiants et la déployer sur Vercel.

## Ce que la page affiche
- Le nom de l'étudiant
- Le groupe
- La note
- Une zone d'annonce en haut de page
- Une recherche par nom avec filtre par groupe

## Déploiement sur Vercel
1. Poussez ces fichiers dans un dépôt GitHub.
2. Importez le dépôt dans Vercel.
3. Déployez-le comme site statique.

## Modifier l'annonce
- Ouvrez la page.
- Déployez **Modifier l'annonce**.
- Saisissez votre message.
- Copiez le lien et envoyez-le aux étudiants.
